# Referencias locales de memoria viva

Esta carpeta conserva la versión adoptada de las referencias de la skill
`gestionar-memoria-viva-proyecto`. Se consulta desde `AGENTS.md`; no sustituye la
documentación específica de Normatividad.

- `resource-efficiency.md`: nivel, presupuesto y uso proporcional de comandos.
- `workflow.md`: inicialización, mantenimiento, auditoría y cierre.
- `detection-strategies.md`: capacidades y límites de detección.
- `http-resource-design.md`: clasificación y propiedad de recursos HTTP.
- `portable-standard.md`: artefactos obligatorios y condicionales.
- `succession-parity.md`: actualización o sustitución futura del estándar.

La copia local se actualiza únicamente mediante una adopción explícita de una nueva versión.
