# Licenciamiento

## Estado

No evaluado. El proyecto todavía no tiene una matriz institucional de dependencias ni una
determinación técnica de régimen. Los archivos `composer.lock` y `package-lock.json` permiten
construir el inventario, pero no sustituyen su revisión.

## Trabajo requerido

1. Generar la matriz de dependencias directas y transitivas de backend y frontend.
2. Evaluar compatibilidad de licencias y obligaciones de distribución.
3. Emitir el informe técnico de determinación.
4. Registrar la decisión institucional y los archivos de licencia aplicables.

Este pendiente no bloquea el desarrollo local, pero sí forma parte del expediente previo a la
publicación institucional.
